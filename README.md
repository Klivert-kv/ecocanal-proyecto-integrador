# EcoCanal – Proyecto Integrador

**Universidad Simón Bolívar, Cúcuta · Ingeniería de Sistemas · Electiva Interdisciplinar I**
Docente: Sandra Elizabeth Rojas Asenjo · 2026

**Integrantes:** Klivert Chiquiza, Andrés Mendoza, Manuel Pinilla, Rafael Ruiz

## De qué trata

Propuesta estratégica para que Veolia Colombia S.A.S. E.S.P. reduzca la reincidencia de puntos críticos de residuos y escombros en el Canal Bogotá de Cúcuta.

EcoCanal combina tres componentes:

- **Chatbot de WhatsApp:** consulta de horarios por barrio, agenda de recolección de escombros y reporte de puntos críticos con foto y ubicación.
- **Tablero georreferenciado:** mapa de reportes y reincidencias para programar limpiezas preventivas.
- **Programa pedagógico:** talleres con Juntas de Acción Comunal y colegios.

## Requisitos (resumen)

- 13 requisitos funcionales (RF-01 a RF-13): horarios, recolección especial, reporte de puntos críticos, seguimiento del caso, notificaciones, autorización de datos, agrupación de reportes, mapa, gestión de casos, reincidencia, indicadores, contenidos pedagógicos y acceso por roles.
- 8 requisitos no funcionales (RNF-01 a RNF-08): disponibilidad, tiempo de respuesta, usabilidad, accesibilidad, seguridad, privacidad (Ley 1581 de 2012), escalabilidad e interoperabilidad.

El detalle de cada requisito está en el documento final.
